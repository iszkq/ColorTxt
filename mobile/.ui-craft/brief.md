# 彩读移动端

用户明确选择保留 ColorTxt 多色正文与工具感。中文优先、文件阅读、离线笔记，iOS 和 Android 触屏操作。沿用 Vue，Capacitor 容器；阅读区采用原生 DOM 选区而非 Monaco。

书架、阅读、笔记、设置为主要流程。工具触控目标至少 48px，适配安全区与键盘。功能色用于对白、高亮、标注，结构界面沿用彩读蓝色。不可将功能入口制作成不可用的装饰按钮。

页面预览工作台：左侧按主要页面、阅读工具和其他状态排列目录，中间用手机容器承载真实应用，右侧说明可操作项。沿用主应用蓝色与中性背景；iOS/Android 尺寸和三主题可切换；窄屏收为横向目录。预览与正式书库隔离，每个入口具有可复制的深链接。

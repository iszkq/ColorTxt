# 彩读 v1.0.2

本次更新重点改善移动端圣经阅读、章节寻找和经文选取。版本统一为 1.0.2；Android versionCode / iOS build number 为 10002。

## 更新内容

- 参考微读圣经公开网页的书卷到章节导航层级，并结合 AndBible、Anx Reader 的开源移动阅读交互，重做移动版圣经选经面板。
- 可切换旧约 / 新约、搜索书卷、以数字网格选章节；开启“精确到节”后可直接定位经文。
- 阅读正文显示独立节号；点起始节和结束节连续选择，或长按正文自由选字。
- 选区显示经文出处，支持复制 / 分享、五色标注、直线、波浪线、马克笔与笔记。
- 优化面板返回焦点、滚动空间、安全区和深色 / 窄屏排版；保持桌面兼容的原文和标注坐标。
- 新增圣经章节 / 节范围及坐标兼容性测试，更新页面预览和移动阅读参考文档。

## 下载与安装

构建完成后，本页附带所有平台的安装包和 `SHA256SUMS.txt`：

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `colortxt-1.0.2-Setup.exe`、`colortxt-1.0.2-Portable.exe` |
| macOS Apple Silicon | `colortxt-1.0.2-arm64.dmg` |
| macOS Intel | `colortxt-1.0.2-x64.dmg` |
| Linux arm64 / x64 | `colortxt-1.0.2-arm64.AppImage`、`colortxt-1.0.2-x86_64.AppImage` |
| Android 7.0+ | `colortxt-1.0.2-android.apk`（签名 APK） |
| iOS / iPadOS | `colortxt-1.0.2-ios-unsigned.ipa`（arm64 真机包，需自行签名） |

Windows 安装包和 macOS 包未使用商业代码签名 / Apple 公证。iOS IPA 不可直接安装；需要用自己的 Apple 证书和描述文件重新签名。

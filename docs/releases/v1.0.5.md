# 彩读 v1.0.5

本次更新完善移动端阅读手势和划线操作。各端版本统一为 1.0.5；Android versionCode / iOS build number 为 10005。

## 更新内容

- 阅读正文左右滑动可按屏幕高度翻页；竖向滚动、短距离轻扫、选区和选字手柄操作不会误触翻页。段落边界可继续进入前后内容段。
- 选中文字后点选底色、直线或波浪线立即生效，不再需要单独点击应用。
- 对已有划线可直接替换线型或颜色，也可取消划线；附带的阅读笔记会保留。
- 优化手机窄屏选区工具栏和触控布局，照顾安全区与小屏宽度。

## 下载与安装

本页构建产物包含以下安装包，并提供 `SHA256SUMS.txt`：

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `colortxt-1.0.5-Setup.exe`、`colortxt-1.0.5-Portable.exe` |
| macOS Apple Silicon | `colortxt-1.0.5-arm64.dmg` |
| macOS Intel | `colortxt-1.0.5-x64.dmg` |
| Linux arm64 / x64 | `colortxt-1.0.5-arm64.AppImage`、`colortxt-1.0.5-x86_64.AppImage` |
| Android 7.0+ | `colortxt-1.0.5-android.apk`（沿用原发布密钥签名） |
| iOS / iPadOS | `colortxt-1.0.5-ios-unsigned.ipa`（arm64 真机包，需自行签名） |

Windows 安装包和 macOS 包未使用商业代码签名 / Apple 公证。iOS IPA 需要自己的 Apple 证书和描述文件重新签名后安装。

## 验证范围

移动端 22 项测试通过，Vue / TypeScript 类型检查与生产构建通过。Chromium 模拟手机尺寸检查覆盖 320px / 360px 宽度、选区工具栏、即时线型替换和取消，以及水平触摸翻页；安卓与 iOS 真机系统栏、软键盘和系统分享仍需设备验收。全部平台通过对应 GitHub Actions 构建后自动发布。

# 彩读 v1.0.4

本次更新重做移动端经文选字、卷章节选择与沉浸阅读。各端版本统一为 1.0.4；Android versionCode / iOS build number 为 10004。

## 更新内容

- 经文选取使用统一的应用内选区，避免与手机系统选字菜单同时出现。长按选中整节，拖动首尾手柄可精确到字、跨节选择、反向调整，并支持文字预览和靠近边缘自动滚动。
- 点节号可连续选择多节；底部集中提供复制、笔记、划线和分享，颜色与线型按需展开。选字操作栏不会挤动正文，保存提示不再阻挡按钮。
- 轻点阅读空白或使用“沉浸”入口收起上下工具栏，再次轻点可恢复；切换时保持原文位置。Android 隐藏系统栏并支持边缘滑动临时唤回，iOS 使用 Capacitor 内置 SystemBars 接口隐藏状态栏并请求自动隐藏 Home 指示条。
- 选经改为左侧分类书卷、右侧章节网格，两栏独立滚动；支持旧约 / 新约切换、书卷搜索、当前经文定位，以及“精确到节”。长书卷名称可以换行，窄屏和深色主题保持清晰。
- 修正按节跳转被顶部工具栏遮挡的问题；返回操作从节到章再关闭选经面板，关闭后恢复焦点。
- 保留原文与桌面兼容的笔记坐标，补充 emoji / 组合字符选区处理、键盘选段和鼠标拖选。

## 下载与安装

本页构建产物包含以下安装包，并提供 `SHA256SUMS.txt`：

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `colortxt-1.0.4-Setup.exe`、`colortxt-1.0.4-Portable.exe` |
| macOS Apple Silicon | `colortxt-1.0.4-arm64.dmg` |
| macOS Intel | `colortxt-1.0.4-x64.dmg` |
| Linux arm64 / x64 | `colortxt-1.0.4-arm64.AppImage`、`colortxt-1.0.4-x86_64.AppImage` |
| Android 7.0+ | `colortxt-1.0.4-android.apk`（沿用原发布密钥签名） |
| iOS / iPadOS | `colortxt-1.0.4-ios-unsigned.ipa`（arm64 真机包，需自行签名） |

Windows 安装包和 macOS 包未使用商业代码签名 / Apple 公证。iOS IPA 需要自己的 Apple 证书和描述文件重新签名后安装。

## 验证范围

移动端 14 项单元测试、Vue / TypeScript 类型检查与生产构建通过。Chromium 移动触摸检查覆盖长按、精确拖动、跨节标注、笔记保存、边缘滚动、沉浸阅读、选经搜索和逐级返回；检查了 320 / 390 / 768px 排版与触摸区域。全部平台通过对应 GitHub Actions 构建后自动发布。

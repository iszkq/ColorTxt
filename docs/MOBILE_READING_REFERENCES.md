## 本轮实现

- 选经使用底部面板，旧约 / 新约分区、书卷名称搜索、章数网格；默认选章立即阅读，开启“精确到节”后再选节。
- 显示当前阅读位置并可返回原文；返回键按节 → 章 → 书卷 → 关闭面板逐层返回，关闭后恢复触发按钮焦点。
- 节号作为独立按钮，点击起始与结束节可连续选择，支持逆序选择；保留系统长按选字和拖动手柄。
- 选区显示书卷、章、节出处，可复制、分享、标注和写笔记。操作栏参与布局，让正文在剩余区域滚动。
- 面板沿用主题与安全区；章数 / 书卷按钮至少 48px，节号和选区操作至少 44px。窄屏书卷网格降为两列，长列表在面板内滚动。

## 原文和坐标约束

圣经原始行仍为 `节号＋全角空格＋正文`。独立节号只改变显示方式，不修改书籍内容。自由选字会把隐藏前缀长度补回坐标；跨行选区保存完整的中间原文行。

标注继续使用从 1 开始的 UTF-16 物理行列范围。整节选取、复制内容及 JSON 导出沿用原文，兼容桌面端的坐标校验。长章仍按最多 120 物理行分段，按节定位可进入后续分段。

## 验收范围

自动化覆盖 1,189 章 / 31,102 节的章网格数据、逆序选节、出处生成与原文坐标校验。浏览器交互验收覆盖前后章、精确到节、诗篇 119:176、自由选字保存、连续选节、复制与面板焦点返回，并检查 320 / 390 / 768px 的深色面板。

另用 Chromium 的移动端触屏模拟完成节号连选 → 选色 → 保存笔记，核对 320px 下的操作区域尺寸、正文剩余空间和长书卷标题。自由选字用真实 DOM Range 验证跨上色片段、段落边界，以及导出笔记的原文坐标；这不替代真机上的长按和手柄操作。

尚需真机验证 iOS / Android 的选字手柄、系统菜单、软键盘、安全区及分享面板。本轮未增加多译本、音频、读经计划或云同步入口。

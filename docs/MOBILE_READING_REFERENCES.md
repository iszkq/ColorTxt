## 本轮实现

- 选经使用实色底部面板，左侧按类别分组的完整书卷目录、右侧章数网格；两栏独立滚动，切换章 / 节时保留书卷上下文。支持旧约 / 新约与名称搜索；默认选章立即阅读，开启“精确到节”后再选节。
- 显示当前阅读位置并可返回原文；返回键从节数网格回到章数网格，再关闭面板，关闭后恢复触发按钮焦点。
- 节号作为独立按钮，点击起始与结束节可连续选择，支持逆序选择。长按正文 380ms 后选中整节，普通文本选中一个字素；使用应用内首尾手柄细选、跨节拖动、反向调整、局部文字预览与边缘自动滚动。正文关闭系统选区及长按菜单，笔记输入框保留系统编辑。
- 选区显示书卷、章、节出处；底部默认只显示复制、笔记、划线、分享，颜色与线型按需展开。操作栏覆盖在阅读区域上，进入选区和沉浸模式都不改变正文位置。被动保存提示不拦截点击。
- 轻点正文空白切换沉浸阅读，或点击工具栏入口；收起上下工具栏，保留微型章节 / 进度与退出入口。滑动和长按不触发切换，返回键先清理当前面板 / 选区再退出沉浸。浏览器仅隐藏应用工具栏；Android 原生插件隐藏系统栏、支持边缘滑动临时唤回；iOS 隐藏状态栏并请求自动隐藏 Home 指示条。
- 面板沿用主题与安全区；章数 / 书卷按钮至少 48px，节号和选区操作至少 44px。窄屏仍保留两栏，低高度屏幕扩大面板，长书卷名称可以换行。普通文本可用键盘选段、方向键调整手柄，也保留鼠标拖选。

## 原文和坐标约束

圣经原始行仍为 `节号＋全角空格＋正文`。独立节号只改变显示方式，不修改书籍内容。自由选字会把隐藏前缀长度补回坐标；跨行选区保存完整的中间原文行。

标注继续使用从 1 开始的 UTF-16 物理行列范围。整节选取、复制内容及 JSON 导出沿用原文，兼容桌面端的坐标校验。长章仍按最多 120 物理行分段，按节定位可进入后续分段。

## 验收范围

14 项单元测试覆盖 1,189 章 / 31,102 节、逆序选节、出处、原文坐标、跨行范围和 emoji / 组合字符。Vue 类型检查与 Vite 生产构建通过。

Chromium 移动上下文使用 CDP 真实触摸事件验收：长按选节、拖动首柄精确选字、跨节连选与波浪线标注、笔记保存、滑动防误触、空白切换沉浸且文字位置不变、Escape 返回、长书卷名和诗篇 119:176。320 / 390 / 768px 深色选经面板检查数字触摸区域至少 44px、无横向溢出。

另验收尾柄跨节、首柄越过尾柄、边缘停留自动滚动、深度滚动后沉浸位置不变、普通文本长按与键盘选段、桌面鼠标拖选。320 / 768px 的展开划线面板保持按钮至少 44px、操作栏位于视口内。

这些浏览器触摸事件不替代真机。当前环境没有 Android / iOS 原生编译工具链；原生插件仅完成源码和 Capacitor API 检查，仍需在各平台编译及真机验证系统栏、手柄、软键盘、安全区和分享面板。
